# Roadmap

This course is being built chapter by chapter, in public, as each one is ready. Current plan:

| # | Chapter | Status |
|---|---------|--------|
| 01 | [Describing the instrument](01-describing-the-instrument/) — electron wavelength, diffraction-limited resolution | Available |
| 02 | [Diffraction physics](02-diffraction-physics/) — wave equation through Howie-Whelan/multislice | Available |
| 03 | [Aberration correction](03-aberration-correction/) — spherical/chromatic aberration, correctors, effect on resolution | Planned |
| 04 | [In-situ electron microscopy](04-in-situ-electron-microscopy/) — in-situ holders, 4D-STEM-based acquisition, reading dynamic data | Planned |
| 05+ | Further chapters (e.g. 4D-STEM/orientation mapping, direct electron detectors) | Not yet scoped |

Chapters are numbered in the order they're meant to be worked through, not necessarily the order they'll be written — a later-numbered chapter may land before an earlier placeholder is filled in, in which case this table will be reordered rather than renumbered in place.

Suggestions or requests for what to cover next are welcome via an issue on this repo.
